# 폰CCTV

안 쓰는 안드로이드 폰을 녹화 전용 CCTV로 쓰는 앱.

## 기능
- 화면을 꺼도(전원 버튼) 계속 녹화 — 번인 걱정 없음
- 설정한 간격(5분~1시간)마다 파일을 저장하고 바로 다음 파일 녹화
- 최대 저장 용량을 넘거나 폰 공간이 부족하면 가장 오래된 영상부터 자동 삭제
- 화질 SD/HD/FHD (CCTV용으로 비트레이트를 낮춰 용량 절약), 전/후면 카메라, 소리 녹음 on/off
- 배터리 잔량·충전 여부·온도 표시
- 영상 위치: 갤러리 → `Movies/CCTV` (파일명 `CCTV_날짜_시간.mp4`)

## 설치
GitHub **Releases**에서 최신 `PhoneCCTV-v1.0.N.apk`를 받아 설치. 같은 서명키로 빌드되므로 새 버전은 덮어쓰기 설치됨.

## 사용 팁
1. 처음 실행 시 카메라·마이크·알림 권한 허용
2. **배터리 최적화 해제** 버튼을 꼭 누르기 (안 하면 몇 시간 뒤 시스템이 녹화를 끊을 수 있음)
3. 삼성폰: 설정 → 배터리 → 백그라운드 사용 제한 → '절전 예외 앱'에 폰CCTV 추가
4. 충전기 연결 상태로 두기. 장시간 충전이 걱정되면 삼성 '배터리 보호(85%)' 기능 켜기
5. 미리보기로 각도를 맞춘 뒤 녹화 시작 → 전원 버튼으로 화면 끄기

## 참고
- 앱을 지우고 다시 설치하면, 그 전에 찍은 영상은 자동 삭제 대상에서 빠짐(직접 지워야 함)
- 서명키(`app/cctv.jks`)가 저장소에 들어 있으니 저장소는 비공개로 두는 것을 권장

## 빌드
`main` 브랜치에 push하면 GitHub Actions가 APK를 빌드해 Release로 올림.
